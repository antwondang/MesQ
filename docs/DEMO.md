# Demo walkthrough

Start with `npm ci`, `npm run build`, and `npm start`, then open http://localhost:3000. The app starts empty; these example entries are fictional and can be deleted afterward.

1. Click **Add application**. Enter **Northstar Labs**, **Software engineering intern**, and **Remote**. Leave the stage Saved, add a future application deadline, and save.
2. Add **Maple Studio**, **Product design intern**. Select Interview, enter **Review portfolio presentation** as the next action, choose a date, and add interview notes.
3. Change Northstar Labs to Applied directly in the list. Open it to inspect the applied date and Activity history.
4. Select **Upcoming**. Maple Studio appears with the next action. Northstar's application deadline no longer appears because it has been applied to.
5. Search for a company or filter a status. **Export CSV** downloads the matching view, including all pages.
6. Open an application, check **Move to archive**, and save. Restore it by unchecking that option in the Archive view.
7. Refresh the browser or restart the app. Saved records remain. Try the same layout on a narrow phone-sized window.

This is a manual tracker. The UI does not generate content, analyze job postings, send applications, or email reminders.
